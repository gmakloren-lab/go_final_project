# Go Task Scheduler API

REST API сервис планировщика задач, разработанный на языке Go.

Проект представляет собой backend-приложение для управления задачами с возможностью создания, изменения, удаления и выполнения задач, а также поддержкой повторяющихся событий.

---

# Описание проекта

Сервис позволяет пользователю управлять задачами через HTTP API.

Основные возможности:

- создание новых задач;
- получение списка задач;
- получение задачи по идентификатору;
- редактирование задач;
- удаление задач;
- завершение задач;
- поддержка повторяющихся задач;
- расчет следующей даты выполнения;
- хранение данных в SQLite;
- автоматическое тестирование API;
- CI через GitHub Actions.

# База данных

В проекте используется SQLite.

Файл базы:

```
scheduler.db
```

Основная таблица:

```
scheduler
```

Структура:

| Поле | Тип | Описание |
|---|---|---|
| id | INTEGER | ID задачи |
| date | TEXT | Дата выполнения |
| title | TEXT | Название задачи |
| comment | TEXT | Комментарий |
| repeat | TEXT | Правило повторения |

# REST API

## Создание задачи

### POST

```
/api/task
```

Пример запроса:

```json
{
    "date": "20260806",
    "title": "Изучить Go",
    "comment": "REST API разработка",
    "repeat": ""
}
```

Ответ:

```json
{
    "id": "1"
}
```

---

## Получение задачи

### GET

```
/api/task?id=1
```

Ответ:

```json
{
    "id": "1",
    "date": "20260806",
    "title": "Изучить Go",
    "comment": "REST API разработка",
    "repeat": ""
}
```

---

## Получение списка задач

### GET

```
/api/tasks
```

Ответ:

```json
{
    "tasks": [
        {
            "id": "1",
            "date": "20260806",
            "title": "Изучить Go"
        }
    ]
}
```

---

## Изменение задачи

### PUT

```
/api/task
```

Пример:

```json
{
    "id": "1",
    "date": "20260807",
    "title": "Изучить Go глубже",
    "comment": "Backend development",
    "repeat": ""
}
```

---

## Удаление задачи

### DELETE

```
/api/task?id=1
```

---

## Завершение задачи

### POST

```
/api/task/done?id=1
```

Логика:

- обычная задача удаляется;
- повторяющаяся задача получает следующую дату выполнения.

---

# Повторяющиеся задачи

Сервис поддерживает повторение задач.

## Каждый год

Формат:

```
y
```

Пример:

```
20260101 + y
```

Следующая дата:

```
20270101
```

---

## Через количество дней

Формат:

```
d N
```

где N — количество дней.

Пример:

```
d 7
```

Задача повторяется каждые 7 дней.
